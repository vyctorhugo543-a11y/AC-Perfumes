## 🚀 Como Hospedar Grátis no GitHub Pages (Passo a Passo)

O GitHub Pages permite que você tenha o site online com link seguro HTTPS (exemplo: `https://seu-usuario.github.io/ac-perfumes/`) de forma 100% gratuita para sempre!

### Método 1: Pelo Navegador no GitHub.com (Mais Fácil e Rápido)

1. Acesse [github.com](https://github.com) e faça login (ou crie uma conta gratuita).
2. No canto superior direito, clique no botão **`+`** e selecione **"New repository"** (Novo repositório).
3. Preencha os campos:
   - **Repository name:** `ac-perfumes` (ou o nome que preferir).
   - Marque a opção **Public** (Público).
   - Deixe desmarcado "Add a README file" (já temos um).
   - Clique no botão verde **"Create repository"**.
4. Na tela seguinte, clique no link **"uploading an existing file"** (enviar arquivos existentes).
5. Arraste todos os arquivos e pastas da pasta `angela_cardoso_perfumaria`:
   - `index.html`
   - `404.html`
   - `.nojekyll`
   - `README.md`
   - Pasta `css` (com `style.css`)
   - Pasta `js` (com `app.js`)
   - Pasta `public` (com as imagens)
6. No rodapé da página, clique em **"Commit changes"**.
7. Agora ative a hospedagem:
   - No topo do repositório, clique na aba **Settings** (Configurações).
   - No menu lateral esquerdo, clique em **Pages**.
   - Em **Build and deployment > Branch**, troque *None* para **`main`** (ou `master`), mantenha a pasta como **`/(root)`** e clique em **Save**.
8. Aguarde cerca de 1 a 2 minutos. Atualize a página e o link do seu site estará pronto no topo:  
   👉 `https://seu-usuario.github.io/ac-perfumes/`

### Método 2: Pelo GitHub Desktop (Aplicativo no Windows)

1. Baixe e instale o [GitHub Desktop](https://desktop.github.com/).
2. Faça login com sua conta do GitHub.
3. No GitHub Desktop, vá em **File > Add Local Repository** e selecione a pasta:  
   `c:\Users\sdk12\Desktop\Site\angela_cardoso_perfumaria`
4. Se solicitar para criar um repositório, clique em **"create a repository"**.
5. Clique em **Publish repository** para enviar para o GitHub.
6. Vá em `Settings > Pages` no GitHub e ative na branch `main`.
